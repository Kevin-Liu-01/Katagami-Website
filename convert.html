The preview is a copy without the site's scripts. To convert the real page, with its scripts running and while you are signed in, run the converter inside it. It rewrites the stylesheets it can read, sweeps every element once, and converts content a single-page app adds later. Reload to undo.

How it decides

Each font stack is judged by its first family, then by its generic fallback. Katagami goes in front and the original stack stays behind it, so any character Katagami does not have falls back to the font the site had. Sites that set fonts through CSS variables are converted where the variable is defined.

The stack starts withBecomesExample
A monospace family, or ends in monospaceKatagami Mono"SF Mono", Menlo, monospace
A serif family, or ends in serifKatagami TextGeorgia, serif
An icon or emoji fontUnchanged"Material Symbols Outlined"
var(--x)Unchanged; --x is converted--font-sans: Inter, sans-serif
inherit, initial or unsetUnchangedfont-family: inherit
Anything elseThe member you pickInter, system-ui, sans-serif

Browsers do not let one site read another's pages, so an address goes through a small relay on this site, /api/fetch, which returns the page, stylesheet and font bytes and nothing else. Pasted HTML never leaves the page.
