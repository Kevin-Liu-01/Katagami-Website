# Katagami website

The specimen site for [Katagami](https://github.com/Kevin-Liu-01/Katagami), live at [katagami.kevinliu.studio](https://katagami.kevinliu.studio).

It is a static site with no build step and one function. The `*-page.html` files are hand-written, and the rest is generated by `tools/build_site.py` in the Katagami repo:

| File | Contents |
|---|---|
| `page.html`, `map-page.html`, `convert-page.html` | the specimen, the map and the converter (edit these) |
| `index.html`, `map.html`, `convert.html` | those pages wrapped in a document, asset URLs stamped with content hashes |
| `katagami-apply.js` | the converter: classifies font stacks and rewrites CSS, HTML or a live page, all in the browser |
| `api/fetch.mjs` | the converter's relay: fetches a public page, stylesheet or font for the browser, since CORS keeps the page from reading other sites |
| `data.js` | metrics, character tables, OpenType features and hero outlines |
| `fonts/*.woff2` | each member's Latin, Greek and Cyrillic core (`KatagamiSans.woff2` …), one file per merged script (`KatagamiSans-thai.woff2` …) and the CJK companions (`KatagamiCJKSC.woff2` …) |
| `fonts/katagami.css` | the `@font-face` rules: each member is one family split by unicode-range, so a page downloads only the scripts it shows |
| `favicon.svg`, `favicon.png`, `apple-touch-icon.png` | the mark, from `tools/logo.py` |
| `map/` | the map's grids and `map.json`, from `tools/build_map.py` |
| `vercel.json` | cache headers, CORS on the fonts, and the redirect from the old kerf.kevinliu.studio address |

To update it, check out this repo next to Katagami, run `tools/build.sh` and `tools/build_site.py` there, then commit and push here. Vercel deploys every push to `main`.
