# Kerf website

The specimen site for [Kerf](https://github.com/Kevin-Liu-01/Kerf), live at [kerf.kevinliu.studio](https://kerf.kevinliu.studio).

It is a static site with no build step and one function. The `*-page.html` files are hand-written, and the rest is generated by `tools/build_site.py` in the Kerf repo:

| File | Contents |
|---|---|
| `page.html`, `map-page.html`, `convert-page.html` | the specimen, the map and the converter (edit these) |
| `index.html`, `map.html`, `convert.html` | those pages wrapped in a document, asset URLs stamped with content hashes |
| `kerf-apply.js` | the converter: classifies font stacks and rewrites CSS, HTML or a live page, all in the browser |
| `api/fetch.mjs` | the converter's relay: fetches a public page, stylesheet or font for the browser, since CORS keeps the page from reading other sites |
| `data.js` | metrics, character tables, OpenType features and hero outlines |
| `fonts/*.woff2` | Kerf Sans, Kerf Round, Kerf Text and Kerf Mono |
| `map/` | the map's grids and `map.json`, from `tools/build_map.py` |
| `vercel.json` | cache headers, CORS on the fonts |

To update it, check out this repo next to Kerf, run `tools/build.sh` and `tools/build_site.py` there, then commit and push here. Vercel deploys every push to `main`.
