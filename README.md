# Kerf website

The specimen site for [Kerf](https://github.com/Kevin-Liu-01/Kerf), live at [kerf.kevinliu.studio](https://kerf.kevinliu.studio).

It is a static site with no build step: `page.html` is the hand-written page, and the rest is generated by `tools/build_site.py` in the Kerf repo:

| File | Contents |
|---|---|
| `page.html` | the page itself (edit this) |
| `index.html` | `page.html` wrapped in a document, asset URLs stamped with content hashes |
| `data.js` | metrics, character tables, OpenType features and hero outlines |
| `fonts/*.woff2` | Kerf Sans, Kerf Round and Kerf Mono |
| `vercel.json` | cache headers |

To update it, check out this repo next to Kerf, run `tools/build.sh` and `tools/build_site.py` there, then commit and push here. Vercel deploys every push to `main`.
